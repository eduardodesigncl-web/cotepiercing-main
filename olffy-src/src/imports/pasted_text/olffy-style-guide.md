OLFFY es una marca chilena de papelería ilustrada, cálida, editorial, juguetona y artesanal. La web no debe sentirse como un dashboard corporativo frío, sino como una extensión privada de la tienda ecommerce. La cuenta cliente debe verse como una “zona privada de la tienda OLFFY”, no como un panel administrativo.

Paleta de color:

Naranja primario: #e94300. Usar en CTAs principales, acentos, precios y estados importantes.

Morado secundario: #5957b0. Usar en bloques destacados, puntos, badges y secciones de fidelización.

Amarillo celebración: #fab405. Usar solo en highlights, iconos especiales o detalles de recompensa.

Crema cálido: #fff5d9. Usar como fondo de descanso o secciones suaves.

Texto principal: #343434. No usar negro puro.

Texto secundario: #6a6a6a.

Blanco como base principal de cards y formularios.

Tipografías:

PiepieW01 para títulos grandes, palabras protagonistas, números de puntos y headings principales.

IvyPresto Text Light Italic para subtítulos editoriales o palabras complementarias poéticas.

Poppins para todo lo funcional: navegación, labels, inputs, botones, body text, precios, estados y microcopy.

Estilo general:

El diseño debe tener layout generoso, limpio y respirado. Usar padding horizontal amplio en desktop, aproximadamente 64px, y 24px en mobile. Las cards deben tener fondo blanco, rounded-2xl, borde sutil rgba(0,0,0,0.07) y sombras muy suaves. Evitar bordes negros gruesos y sombras duras tipo panel admin.

Los botones principales deben ser tipo píldora, rounded-full, en naranja #e94300. Los botones secundarios deben ser blancos con borde suave. Los estados deshabilitados deben ir en gris claro, sin verse rotos.

Mantener la navbar ecommerce: promo bar morada superior con marquee, navbar blanca con logo OLFFY, links Inicio, Tienda, Novedades, Regalos, Nuestra historia, Contacto, e iconos de búsqueda, cuenta y carrito.

El fondo general debe ser blanco con bloques crema cuando se necesite descanso visual. Las pantallas deben verse listas para producción, con buen espaciado y jerarquía.

Criterios finales:

No usar estilo admin.

No usar botones negros como CTA principal.

No usar bordes negros gruesos en todos los elementos.

Mantener la expresividad OLFFY, pero con claridad funcional.

Priorizar legibilidad y coherencia con el ecommerce aprobado.

Diseñar con imágenes placeholder suaves en crema, lila o durazno solo si se necesitan.

Todo debe sentirse como parte del mismo ecommerce OLFFY aprobado.

La cuenta cliente debe usar el sistema visual ecommerce, no el sistema visual admin. Debe sentirse como una sección privada de la tienda OLFFY.
